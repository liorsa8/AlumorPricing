# AlumorPricing — מחשבון הצעות מחיר לחלונות ודלתות

אפליקציית הצעות מחיר פשוטה למפעל אלומיניום/PVC, ללא מנוע CAD — רק רשימת חלונות/דלתות ← הצעת מחיר מוכנה להדפסה.

## הרצה (פיתוח)

```bash
npm install
npm run dev
```

השרת יעלה על `http://localhost:3001` והלקוח על `http://localhost:5173` (הבקשות ל-`/api` מנותבות אוטומטית לשרת).

## הרצה (שימוש יומיומי)

```bash
npm run build
npm start
```

זה בונה את הלקוח והשרת, ומריץ תהליך אחד שמגיש גם את האפליקציה וגם את ה-API בכתובת `http://localhost:3001`.

## גיבוי

כל המידע העסקי (לקוחות, קטלוג מחירים, הצעות מחיר) נשמר בקובץ יחיד:

```
server/data/app.db
```

**גבו את הקובץ הזה באופן קבוע** (למשל העתקה ל-Google Drive / דיסק חיצוני). אין מסד נתונים מרוחק — הכל מקומי.

## מבנה הפרויקט

- `server/` — Express + SQLite (better-sqlite3), חשב את כל המחירים בצד השרת.
- `web/` — React + Vite, ממשק בעברית מימין לשמאל (RTL).

ראו את קובץ התכנון המקורי לפירוט מלא של מודל הנתונים, ה-API, ונוסחאות החישוב.
